# GenPop Sim

**Simulador de Genética de Populações**

GenPop Sim é um software educacional de acesso aberto desenvolvido para apoiar o ensino e a aprendizagem de Genética de Populações no ensino superior. O aplicativo permite explorar, por meio de simulações, processos determinísticos e estocásticos e relacionar parâmetros populacionais às mudanças nas frequências alélicas ao longo das gerações.

## Funcionalidades

A versão 0.3.2 reúne cinco módulos:

1. Deriva genética em populações diploides;
2. Seleção natural em locus dialélico;
3. Estrutura populacional e migração;
4. Ação conjunta de seleção natural e deriva genética;
5. Seleção multialélica com três alelos.

O simulador apresenta trajetórias de frequências alélicas, indicadores-resumo e exportação de resultados, conforme o módulo utilizado. Os componentes estocásticos utilizam amostragem de Wright–Fisher.

## Finalidade

O GenPop Sim foi desenvolvido como ferramenta didática. Seu objetivo é permitir que estudantes formulem previsões, definam parâmetros, executem simulações, observem resultados e comparem cenários de Genética de Populações.

O software não foi desenvolvido ou validado como ferramenta para análises de dados de pesquisa.
